# Window Sticker VIN API

A free, keyless VIN-lookup service that returns the original factory window sticker (Monroney label) PDF plus an NHTSA vPIC specification decode for any 17-character US VIN. Serves decoded vehicle specs, EPA fuel economy, crash ratings, and recalls over an open, CORS-enabled JSON API with no registration.
